3.1 網絡基礎知識

  • LAN（區域網絡）：覆蓋範圍較小，如一間學校或公司。
  • WAN（廣域網絡）：覆蓋範圍廣，可跨越城市或國家，互聯網即為最大的 WAN。
  • WLAN（無線區域網絡）：透過 Wi-Fi 連接的區域網絡。

3.2 互聯網的組成

互聯網（Internet）是由全球無數電腦網絡互相連結而成的網絡，透過標準通訊協定進行資料交換。

名詞說明
ISP（互聯網服務供應商）提供上網服務的公司，例如電訊商
IP 位址每部連上網絡的裝置獨有的識別地址
網域名稱 Domain Name方便記憶的網址名稱，如 example.com
DNS把網域名稱轉換為 IP 位址的系統

3.3 常見通訊協定

協定用途
HTTP / HTTPS瀏覽網頁，HTTPS 為加密版本，更安全
FTP檔案傳輸
SMTP / POP3 / IMAP傳送及接收電郵
TCP/IP互聯網的基礎通訊協定組合，負責封包傳輸及定址

3.4 互聯網的應用

  • 全球資訊網 WWW：透過瀏覽器存取的超連結網頁系統。
  • 電子郵件 Email：透過網絡傳送電子訊息。
  • 即時通訊 Instant Messaging：如 WhatsApp、Telegram。
  • 社交媒體 Social Media：如 Instagram、Facebook，用於分享資訊、交流。
  • 雲端運算 Cloud Computing：透過互聯網提供運算資源、儲存或軟件服務，常見分類：
    • IaaS（基礎架構即服務）
    • PaaS（平台即服務）
    • SaaS（軟件即服務）
  • 物聯網 IoT：把日常物件連接上網絡，互相傳輸資料。

3.5 網絡保安

威脅說明
惡意軟件 Malware包括病毒、蠕蟲、特洛伊木馬，會破壞或竊取資料
釣魚 Phishing假冒可信來源騙取個人資料
黑客入侵 Hacking未經授權存取電腦系統
阻斷服務攻擊 DoS以大量請求令伺服器癱瘓
常見防禦措施：防火牆 Firewall、防毒軟件、資料加密 Encryption、雙重認證 2FA、定期更新系統及備份資料。
