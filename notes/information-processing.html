1.1 資料、資訊與知識

資料（Data）：未經處理的原始事實或數字，本身沒有意義。
資訊（Information）：經過處理、組織後的資料，具有意義及用途。
知識（Knowledge）：透過分析資訊所得出的理解、經驗或洞見，可用作決策。

例子：「85、90、76」是資料；「某班同學平均分為 83.7」是資訊；「該班同學整體表現理想，可考慮加深課程內容」則是知識。

1.3 電腦如何表示資料

電腦內部只能識別 0 和 1（二進制，Binary），所有資料最終都會轉換成二進制碼儲存及處理。

單位大小
1 bit（位元）一個 0 或 1
1 byte（位元組）8 bits
1 KB1024 bytes
1 MB1024 KB
1 GB1024 MB
1 TB1024 GB

1.4 資料處理週期

資料處理一般包括以下四個階段：

  1. 輸入（Input）：透過輸入裝置（鍵盤、掃描器等）將資料送入電腦。
  2. 處理（Processing）：電腦按指令對資料進行運算、排序、篩選等。
  3. 輸出（Output）：以螢幕、打印機等方式呈現處理結果。
  4. 儲存（Storage）：把資料或結果存於硬碟、雲端等儲存裝置，供日後使用。
口訣：輸入 → 處理 → 輸出 → 儲存（Input → Process → Output → Storage，簡稱 IPOS）

1.5 資料與資訊系統的特質

  • 準確性 Accuracy：資料須正確無誤。
  • 時效性 Timeliness：資訊須在有用的時間內提供。
  • 完整性 Completeness：資訊須包含所有必要的內容。
  • 相關性 Relevance：資訊須切合使用者的需要。
  • 可靠性 Reliability：資料來源須可信。
