5.1 演算法 Algorithm

演算法是解決問題的一連串清晰、有限步驟。良好的演算法應具備：

  • 明確性：每個步驟意思清楚，不含糊。
  • 有限性：步驟數目有限，最終會結束。
  • 有效性：每個步驟都能實際執行。

常見表達方式：自然語言、虛擬碼 Pseudocode、流程圖 Flowchart。

5.3 變數與資料類型

變數 Variable 是用於儲存資料的容器，執行程式期間其值可以改變。

資料類型例子
整數 Integer10, -5, 0
浮點數 Float3.14, -0.5
字串 String"Hello", "ICT"

5.4 三種基本程式結構

5.4.1 順序結構 Sequence

程式按照指令先後次序逐一執行。

顯示 "請輸入你的名字"
輸入 name
顯示 "你好，" + name

5.4.2 選擇結構 Selection

根據條件是否成立，決定執行哪一組指令，常見為 IF...THEN...ELSE。

輸入 score
IF score >= 60 THEN
    顯示 "及格"
ELSE
    顯示 "不及格"
END IF

5.4.3 循環結構 Iteration / Loop

重複執行某組指令，直到條件不再成立為止。

total = 0
FOR i = 1 TO 10
    total = total + i
NEXT i
顯示 total
常見循環：FOR 循環（已知重複次數）、WHILE 循環（先檢查條件，符合才執行）、 DO...UNTIL 循環（先執行，後檢查條件）。
