2.1 電腦系統的組成

一個完整的電腦系統由 硬件（Hardware）、軟件（Software） 及 使用者（People） 三部份組成，缺一不可。

2.2 硬件

2.2.1 中央處理器（CPU）

電腦的「大腦」，負責執行指令、運算及控制其他部件。主要包含：

  • 控制器 Control Unit：指揮各部件協調運作。
  • 算術邏輯單元 ALU：進行算術及邏輯運算。
  • 寄存器 Registers：暫存正在處理的資料。

2.2.2 記憶體

類型特性
RAM（隨機存取記憶體）暫存執行中的程式及資料，斷電後資料消失（揮發性）
ROM（唯讀記憶體）儲存開機所需的基本程式，斷電後資料不會消失（非揮發性）
Cache（快取記憶體）速度介乎 CPU 與 RAM 之間，儲存常用資料以加快處理速度

2.2.3 輸入裝置

鍵盤、滑鼠、掃描器、觸控屏、麥克風、攝影機等，用於將外界資料傳送到電腦。

2.2.4 輸出裝置

螢幕、打印機、揚聲器等，用於將電腦處理結果呈現給使用者。

2.2.5 儲存裝置

裝置特點
硬碟機 HDD容量大、價錢相宜，但讀寫速度較慢，有機械部件
固態硬碟 SSD讀寫速度快、耐用、無噪音，但價錢較貴
USB 手指體積小、方便攜帶
雲端儲存透過互聯網儲存資料，方便跨裝置存取及備份

2.3 軟件

2.3.1 系統軟件 System Software

管理及控制電腦硬件運作，例如：

  • 作業系統 Operating System：如 Windows、macOS、Linux、Android，負責管理資源、檔案及執行程式。
  • 工具程式 Utility Software：如防毒軟件、磁碟清理工具。

2.3.2 應用軟件 Application Software

供使用者完成特定工作，例如文書處理（Word）、試算表（Excel）、簡報軟件（PowerPoint）、瀏覽器等。

2.4 電腦系統架構

資料在電腦內以「匯流排 Bus」在 CPU、記憶體及輸入輸出裝置之間傳輸，主要分為： 資料匯流排（Data Bus）、位址匯流排（Address Bus）、控制匯流排（Control Bus）。

2.5 電腦的種類

類型特點
超級電腦 Supercomputer運算能力極強，用於科學研究、天氣預測
大型主機 Mainframe可同時處理大量交易，銀行、政府機構常用
個人電腦 PC供個人日常使用
流動裝置 Mobile Device如智能手機、平板電腦，方便攜帶
嵌入式系統 Embedded System內置於其他裝置中，如洗衣機、汽車
