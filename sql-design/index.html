試算區

本頁的 SQL 規則按 MySQL 8.0（字串比較及 LIKE 不分大小寫、/ 是實數除法、聚合函數不計 NULL、ONLY_FULL_GROUP_BY）；語句用 DSE 卷二寫法（單引號、% _、MINUS）。FULL JOIN 及 MINUS 是 DSE 附頁的寫法，MySQL 不支援（上機改用 LEFT JOIN … UNION … RIGHT JOIN 及 EXCEPT／NOT IN）。實體關係圖記法按 DSE 2025 附頁。
