Q1. 寫出判斷一個數字是否為偶數的虛擬碼。 
輸入 num
IF num MOD 2 == 0 THEN
    顯示 "偶數"
ELSE
    顯示 "奇數"
END IF
Q2. 以下程式碼執行後，total 的最終值是多少？ 
total = 0
FOR i = 1 TO 5
    total = total + i
NEXT i
total = 1+2+3+4+5 = 15
Q3. FOR 循環與 WHILE 循環有何分別？各適合在甚麼情況使用？
FOR 循環適用於已知重複次數的情況（例如重複 10 次）； WHILE 循環則在執行前先檢查條件是否成立，適用於重複次數不確定、視乎條件而定的情況 （例如不斷輸入直至使用者輸入 "quit" 為止）。
Q4. 判斷以下程式碼屬於順序、選擇還是循環結構？ 
score = 45
IF score >= 60 THEN
    顯示 "PASS"
ELSE
    顯示 "FAIL"
END IF
屬於選擇結構（Selection），因為程式會根據 score 的值決定執行哪一組指令。
Q5. 以下程式試圖計算兩數之和，但出現錯誤，請指出屬於哪一類錯誤並改正： 
a = 5
b = 3
print(a + )
屬於語法錯誤（Syntax Error），因為 print(a + ) 缺少了第二個運算元，不符合程式語言的文法規則。 改正：print(a + b)
