Q1. HTTP 與 HTTPS 有何分別？為何登入銀行網站時應使用 HTTPS？
HTTPS 是 HTTP 的加密版本，透過 SSL/TLS 加密瀏覽器與伺服器之間的通訊。 登入銀行網站涉及帳戶密碼等敏感資料，使用 HTTPS 可防止資料在傳輸過程中被第三者截取或竄改。
Q2. DNS 的作用是甚麼？
DNS（域名系統）負責把使用者容易記憶的網域名稱（如 www.example.com）轉換成電腦可識別的 IP 位址， 使瀏覽器能夠找到正確的伺服器。
Q3. 判斷以下屬於雲端服務的哪一類：(a) Google Docs (b) 租用虛擬伺服器 (c) 應用程式開發平台如 Heroku
(a) SaaS（軟件即服務）。
(b) IaaS（基礎架構即服務）。
(c) PaaS（平台即服務）。
Q4. 甚麼是「釣魚（Phishing）」攻擊？學生應如何防範？
釣魚是指不法分子假冒可信任的機構或個人（如銀行、學校），以電郵或訊息誘騙受害人提供個人資料或密碼。
防範方法：不隨意點擊可疑連結、核實寄件人身份、不在不明網站輸入個人資料、開啟雙重認證。
Q5. 簡述防火牆（Firewall）的作用。
防火牆是硬件或軟件系統，用於監察及控制進出網絡的資料流量， 根據預設規則阻擋未經授權的存取，保護內部網絡及裝置免受外來攻擊。
